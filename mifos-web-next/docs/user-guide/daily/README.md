## How this volume will grow

1. Pick one role (recommend **Tellers** or **Checkers** first — shortest feedback loop).
2. List the top 5–10 tasks that role performs weekly.
3. Write one task page each with Mermaid + screenshot placeholders, then capture screenshots from sandbox.
4. Link back to Administrator setup pages when a day-to-day failure is actually a configuration gap.
